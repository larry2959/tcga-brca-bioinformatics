# Lead integration checklist

- Confirm the approved question/objectives.
- Inspect each member's pull request and verify files/outputs.
- Resolve notebook merge conflicts carefully; don't overwrite contributions silently.
- Run the notebook from a clean Colab runtime, top-to-bottom.
- Confirm cohort and metric counts against exported outputs and slides.
- Review interpretations for unsupported causal/clinical claims.
- Verify citations, GitHub accessibility, reflections and presentation readiness.
