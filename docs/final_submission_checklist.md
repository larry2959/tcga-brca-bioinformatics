# Final quality gate

- [ ] Lecturer-approved research question and 2–4 objectives documented.
- [ ] Real biological dataset, source, cohort criteria, file descriptions and variables documented.
- [ ] Notebook stages are in required order and each has interpretation.
- [ ] Preprocessing/QC: before-after counts and suspicious observations discussed.
- [ ] At least three informative EDA plots with interpretation.
- [ ] Core analysis has result table, figures and statistical evidence; FDR correction explained.
- [ ] Biological interpretation linked to the research question; any enrichment actually performed and reported.
- [ ] ML baseline/model, split, feature selection, metrics and limitations documented; leakage prevented.
- [ ] Notebook runs top-to-bottom in Colab and saved outputs are visible.
- [ ] Results and presentation numbers agree.
- [ ] GitHub link accessible; member commits and contribution log are genuine.
- [ ] Each person submits their own reflection PDF (max 1 page) with role, challenges and achievements.
- [ ] Presentation team can answer questions and state limitations honestly.
